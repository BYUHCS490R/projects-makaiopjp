Images

What kind of photos are good to encode using JPEG? Photos from your phone, or real world photos with a lot of colors.

What kind of photos are good to encode using GIF? Using pictures that don't have a lot of colors or transparency.(cartoon like, Logos, or photoshop)

What is unique about the PNG format? Good for Logos. It has transparency support.

How do you resize your photo to the size it should be displayed? Download and use a photo editing software like GIMP or Photoshop to resize the image.

Why should you resize photos using photo editing software instead of resizing it using CSS? Because CSS only changes the display size, not the actual file size, which can cause performance issues.

What is CSS validation? validation checking CSS code for errors and ensuring it's in standards.
