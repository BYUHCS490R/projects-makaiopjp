Box Model

What is the difference between block tags and inline tags?

Block tags create a new line and take up the full width of their container. Inline tags do not start a new line, only takes up as much width as necessary.

What is the margin, border, and padding?

Margin is the space outside the border of an element. Border is the line that surrounds an element. Padding is the space inside the border of an element.

what are units of measurement you can use in CSS?

CSS units include pixels, centimeters, inches, em units, rem units, percentages.

when would you use a figure tag?

The figure tag is used to group an image with its caption or description. It is semantically correct and helps improve accessibility.
