CSS Selectors

Different ways to select an item is by useing the ID or CLASS selectors.

the difference between an ID and a CLASS is that an ID can only be used once on a page, while a CLASS can be shared by multiple elements.

the difference between a SPAN tag and a DIV tag is that a SPAN is an inline element and a DIV is a block element.

the difference between a DIV tag and a HEADER, MAIN, or FOOTER is almost nothing. they all have the same purpose of grouping content. but google sees it as different semantic meaning.

the different ways to select colors in CSS are by using a color name, an RGB 0-255 value, an Hex code, or short Hex code.
